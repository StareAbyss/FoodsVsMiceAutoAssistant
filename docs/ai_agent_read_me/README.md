# AI 必读文档

新任务接手本仓库时，先阅读 [AI 工作总则](./AI工作总则.md)。总则只规定跨任务的决策原则；需要具体解决方案、操作步骤或验收标准时，必须根据任务类型阅读下面对应的专项文档，不能只凭总则直接执行。

只需阅读与当前工作相关的文档；一项任务同时涉及多个领域时，应组合阅读对应文档。

## 按任务查阅

| 当前工作 | 执行前必须阅读 |
| --- | --- |
| 运行项目、安装依赖、选择测试环境、整理 `tool/` 或 `test/` | [项目运行环境和调试环境](./项目运行环境和调试环境.md) |
| 编写或修改函数注释、docstring、类型标注 | [代码风格](./代码风格.md) |
| 新增路径、读取资源、调整 `RESOURCE_P`、迁移资源目录 | [全局路径和资源管理](./全局路径和资源管理.md) |
| 创建 commit、PR、审核、合并或同步分支 | [提交并 PR](./提交并PR.md) |
| 修改热更新、版本号、更新节点或移动 tag | [版本更新主分支开发规范](./版本更新主分支开发规范.md)；涉及 PR 时同时阅读 [提交并 PR](./提交并PR.md) |
| 生成发行包、修改启动器、镜像、图像资源生成或本地凭据 | [打包与部署](<./打包 & 部署.md>) |
| 排查 PyCharm、Codex、ACP、解释器或 PATH | [AI 智能体所需环境配置](./AI智能体所需环境配置.md) |
| 获取、分类或比对战利品图像资源 | [战利品资源与失败样本处理规范](../../tool/item_resource/README.md) |
| 修改版本更新时的配置迁移规则 | [版本更新与配置迁移方案 TODO](../ai_agent_todo_list/版本更新与配置迁移方案TODO.md) |

## 查阅后执行

专项文档提供默认流程，但不能代替源码核对。文档无法覆盖用户当前任务的明确要求时，以用户最新要求为准；发现文档与源码冲突时，应核对当前实现并同步修正文档，而不是沿用过时描述。
