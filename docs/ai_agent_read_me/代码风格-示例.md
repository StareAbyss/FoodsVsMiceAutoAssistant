# 代码风格示例

本文件是 [代码风格.md](./代码风格.md) 的配套示例集。
轻度开发不需要默认读取；需要书写复杂代码、复杂注释或无法判断具体写法时，再查阅对应章节。

## 函数作用域示例

只服务于刷新流程的识图步骤应放在外层流程内部：

```python
def reload_game(self):
    def try_enter_server() -> bool:
        """识别当前平台的选服入口并点击。"""
        ...

    return try_enter_server()
```

如果同一逻辑需要被多个流程调用、独立测试或由子类覆写，则提升为类方法或模块级函数。

## Google 风格 docstring

```python
def some_function(arg_a, arg_b=None):
    """
    简短说明这个函数完成的业务目标，必要时补充调用阶段。

    如果流程复杂，可以继续说明关键规则和失败行为。

    Args:
        arg_a: 参数含义，以及必要的取值范围或特殊值。
        arg_b: 参数含义；说明默认值代表什么。

    Returns:
        返回值的结构和业务含义。

    Raises:
        ValueError: 输入不符合业务约束时抛出。
    """
```

## 中文 docstring 换行

不推荐：

```python
"""
最终物理顺序保持为：方案卡、独立任务卡、第一承载、其他辅助卡、
第二张及后续承载。任务卡若由已有卡承担，就只给该实体卡追加角色，
不会额外占据一个物理槽位。
"""
```

推荐：

```python
"""
最终物理顺序保持为：方案卡、独立任务卡、第一承载、其他辅助卡、第二张及后续承载。
任务卡若由已有卡承担，就只给该实体卡追加角色，不会额外占据一个物理槽位。
"""
```

应按照语义完整性换行，不要仅按字符数量截断句子。

## 行上注释与数据结构

```python
# 默认表示识别异常。
result_drop_by_dict[p_id] = {"loots": None, "chests": None}

# 使用识别成功的战利品计数更新排序文件，不把“识别失败”写入排序数据。
best_match_items_success = [
    item for item in copy.deepcopy(list(loots_dict.keys()))
    if item != "识别失败"
]
```

## 多行注释换行

不推荐：

```python
# 一般辅助卡位于第一承载之后、后续承载之前。它们允许找不到；如果
# 同时承担任务角色，任务解析会自动将 can_failed 提升为 False。
```

推荐：

```python
# 一般辅助卡位于第一承载之后、后续承载之前。它们允许找不到；
# 如果同时承担任务角色，任务解析会自动将 can_failed 提升为 False。
```

连接成分应与其引导的分句位于同一行。

## 异常和兜底说明

```python
def load_ranking(json_path):
    """
    读取主排序文件；文件损坏时使用 resource/template 中的备份文件兜底。

    该兜底可避免排序文件被清空后中断战斗结算，但本次运行不会保留损坏文件中的数据。

    Args:
        json_path: config 中的可写排序文件路径。

    Returns:
        排序数据；备份也不可用时返回空结构。
    """
```

这里同时说明了失败原因、继续运行的依据和可能的数据损失。
