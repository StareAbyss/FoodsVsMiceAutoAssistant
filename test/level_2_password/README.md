# 二级密码后备路线验证

## 自动测试

在项目根目录运行：

```powershell
uv run python -m unittest test.level_2_password.test_password_flow -v
```

测试隔离窗口、动作队列和 Qt，仅载入实际业务方法。覆盖暗晶未弹框转后备、两路失败通知并停止、空密码阻止点击、错误密码不继续整理、后备只点击一次整理、未弹框不输入密码，以及删除/兑换/分解任务的密码失败和玩家启用范围。

## 2026-10-02 游戏实测

- 使用项目已有截图、窗口句柄、动作队列及 `common/二级密码.png` 模板，未新增图片资源。
- 密码标题实测矩形为 `[377, 186, 416, 205]`，识别范围在四周各留 10 像素。
- 直接运行当前工作树的卡片背包后备函数：进入防御卡、点击一次整理、输入本机配置的密码、确认密码框消失、关闭背包，返回 `True`。
- 按用户要求调用主目录已有的新版 `reload_game()`，完整关闭健康公告和节日活动后确认主页，返回 `True`。
- 在诊断入口模拟暗晶入口失败，再运行当前工作树的完整密码方法：自动走实际后备路线，识别到密码框，解锁成功并返回 `True`。未进行暗晶购买或删除物品。
- 9 项自动测试通过；三个修改的业务文件通过 Python 语法编译和 `git diff --check`。

当前背包未满，因此未实测“背包超过上限后暗晶购买”的真实场景；该分支使用隔离测试验证。

早期复测中曾在刷新状态未可靠确认时重复点击整理，导致实际卡片排列改变，已告知用户。完整刷新流程确认后再次实测成功。已解锁或未设置二级密码时，首次后备点击仍可能直接整理，这是此触发方式的固有副作用；程序未识别到密码框时会停止任务并提示，不会再次点击整理。

失败时通过现有 `SIGNAL.DIALOG` 通知、`SIGNAL.END` 停止任务序列，FAA 界面保留以显示提醒。
